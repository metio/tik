`tik` alone prints the full usage text, which is the authoritative
reference. These pages group the verbs by what you are trying to do.

- [Recording work](/cli/recording-work/) — creating tickets, asserting
  facts, attaching evidence, correcting mistakes.
- [Reading a store](/cli/reading-a-store/) — the inbox, the board,
  explain, history, and counterfactuals.
- [Store administration](/cli/administration/) — identity, roles,
  verification, migration, and packaging.

Two conventions run through all of them. Any lens takes `--edn` or
`--format json` for machine output, and any ticket id can be abbreviated to
a unique prefix, the way git accepts short SHAs.
